# BlueCloud Launcher 0.7.0 for Windows

Download **BlueCloud-Launcher-Setup-0.7.0-x64.exe** to install or update the launcher.

- **New logo and simpler interface.** A light blue-and-white library, clearer typography, more space and squircle logos bring the launcher in line with the BlueCloud website. The BlueCloud logo appears in the header, Windows app icon and installer.
- **Doc Cloud and Sheet Cloud are coming soon.** Discover the document and spreadsheet apps with their new artwork. These preview cards clearly show Coming soon and cannot start an installation or join an install-all operation.
- **Tooldeck 0.5.1 is available.** The new red toolbox logo appears throughout Tooldeck and its Windows icons. Its 79 local tools include PDF, image, video, audio, conversion and everyday utilities, with bundled runtimes for offline processing.
- **Updated app and release systems.** App-owned packages, signed release metadata and SHA-256 verification connect this release to the live update feed. Release notes and source links remain available from the library.
- **Download and update controls.** Pause and resume downloads across restarts, see download size, speed and remaining time, install or update available apps together, and restore an app's previous installed version.
- **Native Windows updater.** The independent update helper confirms startup, survives Launcher exit and verifies the installed files before recording success. A staged update can be restarted now or deferred until later.
- **Your library stays yours.** Existing Windows app identifiers, installed apps, profiles, settings and downloaded content are retained. Installed apps remain available offline, and no account is required to manage them.

Windows x64 alpha preview. This release remains unsigned. Source, app metadata, runtime-integrity metadata and SHA-256 checksums accompany the release. Doc Cloud and Sheet Cloud are not published in the installable release feed yet.
