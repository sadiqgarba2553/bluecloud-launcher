# BlueCloud Launcher 0.7.1 for Windows

Download **BlueCloud-Launcher-Setup-0.7.1-x64.exe** to install or update.

- **Doc Cloud is available.** Free local documents, rich text, editable templates, comments, named history and basic document import/export.
- **Sheet Cloud is available.** Free local workbooks, formulas, formatting, editable templates, named history and basic XLSX/CSV import/export.
- **New app logos and updated systems.** Both apps use their supplied squircle artwork throughout the library and Windows builds. The catalog, app-owned release routing and signed download tickets now support both apps.
- **Install and manage all five apps.** Individual installation, install all, verified downloads, pause/resume, previous-version recovery and offline access remain available.
- **Existing data stays in place.** App identifiers, profiles, settings and installed libraries are preserved.

Windows x64 alpha preview; packages are unsigned. Doc Cloud and Sheet Cloud are development editions with limited Office conversion. They do not provide full Word/Excel fidelity or hosted collaboration. WebView2 is required. See each app’s release notes and known limitations.
